# Тренажёр фотоидентификации МФО

Интерактивный тренажёр для сотрудников отдела фотоидентификации МФО.

## 🎯 Цель

Симуляция реальных кейсов проверки документов. Сотрудник проходит 30 практических ситуаций, принимает решения и получает оценку.

## 🕹️ Как работает

1. Введи ФИО.
2. Система загружает случайные кейсы из базы данных.
3. Для каждого кейса:
   - Показывается фото документа + описание.
   - Сотрудник заполняет анкету (ФИО, паспорт, дата рождения и т.д.).
   - Нажимает «Принять» или «Отклонить» с указанием причины.
4. Система проверяет правильность и сохраняет результат в БД.
5. В конце — процент успешно пройденных кейсов.

## 🛠️ Технологии

- Python 3.10+
- Streamlit — веб-интерфейс
- PostgreSQL — база данных кейсов и результатов
- psycopg2 — подключение к БД
- python-dotenv — переменные окружения
